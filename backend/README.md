# RADIX Talent Match — Backend API & Supabase Integration (Role 3: Profile Builder)

This Python FastAPI service provides validation, Supabase persistence, and retrieval for candidate profiles generated by the RADIX Profile Builder.

---

## 1. Architecture Overview

- **Framework:** FastAPI with Pydantic v2 data models.
- **Database:** Supabase (PostgreSQL with JSONB structured profile storage).
- **Data Exchange:** Standard RADIX JSON contract shared with Role 2 (Resume Parsing), Role 4 (Talent Check), and Role 5 (Skill Matching).

---

## 2. Supabase Database Schema

To set up your table in Supabase SQL Editor:

```sql
CREATE TABLE IF NOT EXISTS candidate_profiles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name TEXT NOT NULL,
    email TEXT NOT NULL,
    profile JSONB NOT NULL,
    created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL,
    updated_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Index on email and created_at for fast queries
CREATE INDEX IF NOT EXISTS idx_candidate_profiles_email ON candidate_profiles(email);
CREATE INDEX IF NOT EXISTS idx_candidate_profiles_created ON candidate_profiles(created_at DESC);
```

## 3. Quickstart & Installation

```bash
# 1. Navigate to backend directory
cd backend

# 2. Create and activate a Python virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure environment variables
cp .env.example .env
# Edit .env and supply your SUPABASE_URL and SUPABASE_KEY
```

---

## 4. Running the Server

```bash
uvicorn app.main:app --reload --port 8000
```

- API Docs: `http://localhost:8000/docs`
- Health check: `http://localhost:8000/api/health`

## 5. API Endpoints

### `POST /api/profiles`
Save a new candidate profile.

**Request Body:**
```json
{
  "name": "Alex Morgan",
  "email": "alex.morgan.cs@university.edu",
  "phone": "+1 4158902341",
  "education": [
    {
      "degree": "Bachelor's Degree",
      "field_of_study": "Computer Science",
      "institution": "University of California, Berkeley",
      "graduation_year": "2025"
    }
  ],
  "skills": [
    {
      "skill_name": "TypeScript / React",
      "category_code": "COD",
      "evidence": "Built full-stack applications",
      "confidence": "high"
    }
  ],
  "hackathons": [],
  "internships": [],
  "certifications": [],
  "preferred_roles": ["Frontend Engineer"],
  "cv_file": "alex_morgan_resume.pdf"
}
```

**Response (201 Created):**
```json
{
  "id": "e4b2568f-9e73-4ac8-b80c-7b08499292a8",
  "profile": { ... },
  "created_at": "2026-10-26T18:00:00Z",
  "updated_at": "2026-10-26T18:00:00Z"
}
```

### `GET /api/profiles/{profile_id}`
Retrieve a saved candidate profile by its persistent UUID. Used by Role 4 (Talent Check) and Role 5 (Skill Matching).

### `PUT /api/profiles/{profile_id}`
Update an existing candidate profile.

### `GET /api/profiles?limit=20&offset=0`
List candidate profiles with pagination.

### `DELETE /api/profiles/{profile_id}`
Delete a candidate profile.
